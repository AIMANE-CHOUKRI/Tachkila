# Tachkila
Développer une application interactive de composition d'une équipe de football en 4-4-2 à l'aide de HTML, CSS (Tailwind CSS et CSS Grid) et JavaScript (DOM). L'application devra être responsive, et offrir une interface fluide, claire et intuitive.
